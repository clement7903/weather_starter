# Themes

This file collects the suggested themes, descriptions, and design considerations from `suggested_themes.txt`.

---

## Clear Sky

Description: Bright, airy interface with a daylight feel.

Main visual choices:

- Color: Soft sky blues (#E6F7FF, #8ECFFF) with warm yellow accents
- Typography: Humanist sans (Inter / Roboto)
- Card styling: Light cards with soft 8px radius and subtle drop shadows
- Layout density: Spacious (generous padding and large touch targets)

---

## Midnight

Description: Sleek dark UI optimized for night-time use.

Main visual choices:

- Color: Deep navy/indigo (#071029, #123154) with cyan highlights
- Typography: Geometric sans (Montserrat / Poppins)
- Card styling: Elevated dark cards with thin neon borders
- Layout density: Medium (grouped content, moderate spacing)

---

## Minimal

Description: Clean, data-first design with extreme clarity.

Main visual choices:

- Color: Off-white background, neutral grays, single accent color
- Typography: Neutral sans (Helvetica Neue / Inter) with tight weights
- Card styling: Flat, border-only cards, 4px radius
- Layout density: Dense (compact lists and small gaps)

---

## Sunrise

Description: Warm, optimistic theme inspired by dawn.

Main visual choices:

- Color: Peach, coral, and warm gold gradients
- Typography: Friendly sans-serif (Rubik / Nunito)
- Card styling: Soft rounded cards with warm gradient headers
- Layout density: Airy (large headers, roomy cards)

---

## Storm

Description: Dramatic, high-energy theme for intense weather visuals.

Main visual choices:

- Color: Charcoal, slate, stormy teal, and electric orange accents
- Typography: Condensed sans (Oswald / Be Vietnam) for headlines
- Card styling: Heavy borders, textured backgrounds, subtle grain
- Layout density: Medium (emphasis on big hero panels)

---

## Vintage

Description: Analog-inspired, warm and nostalgic aesthetic.

Main visual choices:

- Color: Muted sepia, olive, and dusty blues
- Typography: Serif for headings (Merriweather) + mono/serif for data
- Card styling: Paper-like cards with thin borders and slight noise
- Layout density: Relaxed (generous margins and stacked blocks)

---

## High Contrast

Description: Accessibility-first, strong legibility theme.

Main visual choices:

- Color: Black/white base with bold accent (yellow or cyan)
- Typography: Large, high-x-height sans (Arial/Inter) with strong weights
- Card styling: Clear outlines, high-contrast backgrounds, large icons
- Layout density: Sparse (lots of whitespace for readability)

---

## Neumorphism

Description: Soft, tactile UI with subtle extruded elements.

Main visual choices:

- Color: Very light grays with gentle highlights/shadows
- Typography: Rounded sans (Circular / Nunito) for friendly feel
- Card styling: Soft inner/outer shadows, pill shapes, minimal borders
- Layout density: Medium (balanced spacing to show depth)
